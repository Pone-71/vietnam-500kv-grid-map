# Vietnam 500kV Grid Map

Interactive HTML/SVG visualization of Vietnam's 500kV transmission grid, mapping the three
major circuits (Mạch 1 – 1994, Mạch 2 – 2005, Mạch 3 – 2024) with a tilted 3D-style map view.

## Features
- Interactive legend to toggle circuits on/off
- Animated circuit drawing
- Includes Hoàng Sa/Trường Sa island markers

## Tech stack
HTML, CSS, SVG, JavaScript

## How to view
Download `map_3d_500kv_bg.html` and open it in any browser.
